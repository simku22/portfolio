# Building My Portfolio

Welcome to my new portfolio! I built this site to showcase my work and experience.

## Tech Stack

I chose **Astro** because of its performance-first approach and island architecture. It allows me to write standard HTML/CSS/JS while still having the power of components when I need them.

For styling, I used **Tailwind CSS** (v4) for a utility-first approach that makes iterating on design quick and easy.

## Features

- **Dark Mode**: A fully functional dark mode that respects system preferences.
- **Animations**: Smooth page transitions and element animations using standard CSS and simple JS.
- **Content**: A blog section (you're reading it right now!) powered by Markdown.
